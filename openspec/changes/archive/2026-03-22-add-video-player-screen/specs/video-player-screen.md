# Spec: Video Player Screen

## Overview
Add a Video Player screen to untitled.pen using pencil MCP batch_design tools, following the existing design system patterns.

## Requirements
1. Screen matches existing 1440x1200 light theme layout
2. Sidebar copied from existing screens with "Video Player" as active item
3. Video viewport shows dark area with face recognition bounding boxes
4. Info panel displays metadata and recognition statistics
5. Playback controls include transport, progress bar, speed, and volume
6. Bottom panel has contestant timeline and flagged detections
7. All components reuse existing design system IDs
