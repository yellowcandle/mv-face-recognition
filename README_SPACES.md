# 🎬 MV Face Recognition System

Advanced AI-powered face recognition system for video analysis, built with Gradio 5.x.

## 🌟 Features

### 📷 Real-time Camera Recognition
- Live webcam face detection and recognition
- Real-time processing with visual feedback
- Adjustable recognition thresholds

### 🖼️ Image Analysis
- Upload images for face detection
- Drag-and-drop interface
- Detailed analysis results

### 🎬 Video Processing
- Upload and process video files
- Frame-by-frame face recognition
- Export processed videos with annotations

### 👥 Contestant Management
- Add new contestants to the database
- Manage face embeddings
- View contestant information

### 📊 Analytics Dashboard
- Performance metrics visualization
- System status monitoring
- Real-time statistics

### ⚙️ Advanced Configuration
- GPU acceleration support
- ChromaDB vector database integration
- Customizable detection parameters

## 🚀 Technology Stack

- **Frontend**: Gradio 5.x with modern Ocean theme
- **AI Model**: InsightFace for face recognition
- **Vector DB**: ChromaDB for fast similarity search
- **Processing**: OpenCV for image/video processing
- **Visualization**: Plotly for interactive charts
- **Backend**: FastAPI integration ready

## 🔧 Usage

1. **Live Camera**: Click on the Live Camera tab to start real-time face recognition
2. **Image Upload**: Drag and drop images for analysis
3. **Video Processing**: Upload videos to process and annotate with face recognition
4. **Settings**: Adjust recognition thresholds and system parameters
5. **Analytics**: Monitor system performance and statistics

## 📋 System Requirements

- Python 3.11+
- 8GB+ RAM recommended
- GPU support (CUDA/Metal) for optimal performance
- Webcam for live recognition features

## 🎯 Use Cases

- Video content analysis
- Security and surveillance
- Entertainment industry applications
- Research and development
- Educational demonstrations

## 🔒 Privacy & Security

- All processing happens locally
- No data is sent to external servers
- Face embeddings are stored securely
- Optional authentication for private deployments
