## Summary
Primary: Detect and recognize contestants in videos using embeddings from photos, output annotated frames/videos. Approach: Use insightface for detection/embeddings, supervision for tracking, OpenCV/ffmpeg for annotation; integrate with existing ChromaDB.

## Technical Context
**Language/Version**: Python 3.11 / TypeScript 5.x  
**Primary Dependencies**: insightface, supervision, opencv-python, chromadb, sveltekit  
**Storage**: ChromaDB for embeddings; file system for videos/frames  
**Testing**: pytest (Python), vitest (JS)  
**Target Platform**: Web (browser/server), Linux/Mac  
**Project Type**: web  
**Performance Goals**: 30fps processing on CPU; <10s for 1min video  
**Constraints**: Preserve original audio/color; offline capable  
**Scale/Scope**: 96 contestants; videos up to 10min
