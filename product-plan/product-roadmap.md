# Product Roadmap

## Sections

### 1. Video Player
Interactive video viewer with real-time face overlays, contestant thumbnails, and bounding boxes during playback.

### 2. Contestant Directory
Browse all contestants with photos, view their appearance history, and search/filter by name.

### 3. Analytics
Dashboard showing screen time stats, co-appearance patterns, and appearance trends across videos.

### 4. Video Ingestion
Admin interface for submitting YouTube URLs, monitoring processing status, and managing the video library.

### 5. Face Flagging
Correction workflow where users flag incorrect identifications to improve recognition accuracy over time.
