You are implementing a complete MV Face Recognition system with a "Cyber-Refined" aesthetic.

## Design System
- **Colors**: Blue (primary), Sky (secondary), Slate (neutral) with Amber accents
- **Typography**: Noto Sans TC for UI text, JetBrains Mono for technical data
- **Aesthetic**: High-tech, dark theme with glassmorphism effects

## Complete Implementation
1. **Foundation**: Design tokens, data model, routing
2. **Shell**: Navigation, layout, user management
3. **Sections**: Video Player, Contestant Directory, Analytics, Video Ingestion, Face Flagging
4. **Integration**: Cross-component navigation and state management

## Technical Requirements
- React components with TypeScript
- Props-based architecture (no direct data imports)
- Mobile-first responsive design
- Dark/light mode support
- Accessibility compliance
- Error handling and loading states

The components feature sophisticated animations, glassmorphism effects, corner frame overlays, and precision status indicators. All are production-ready.
